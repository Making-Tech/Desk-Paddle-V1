# Desk Paddle V1
Desk Paddle V1 is a sleek, easy to use capacitive touch pad. It contains 4 TTP223 modules with an ESP32 C3 Supermini module from Amazon. It runs ESPHome and a blueprint to control Home Assistant.

## 3D Files
The 3D files and Directions for this project are located on MakerWorld and Printables page. 

## Blueprint
Press the button below to install the blueprint onto your Home Assistant server.
